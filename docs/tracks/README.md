每篇记录建议包含：

1. 目的与变更：这次运行要验证什么，代码或配置相对上次改了什么。
2. 环境与配置：数据、区间、成本、模型、关键依赖版本、运行文件。
3. 结果：每轮的假设、策略、样本内指标，样本外指标单独列出。
4. 问题：现象、证据（数字或日志）、原因判断。
5. 建议：按优先级列出，标明状态（待办 / 进行中 / 已完成，附提交）。
6. 复现：命令和运行文件。
